# K6 Restful Booker

This project runs a k6 performance test against the Restful Booker API and generates an HTML report.

## Run the test

From `K6-Restful-Booker`:

```bash
npm install
npm run perf
```

## Output

- The main test script is `k6-tests/booker.js`
- The HTML report is generated by `handleSummary(data)`
- Report output is saved to `k6-report/report.html`

## Notes

- `summary.json` is not required for the HTML report generation.
- `handleSummary` receives the k6 summary object and builds the report at the end of the run.
